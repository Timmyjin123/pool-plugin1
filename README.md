# Pool — плагин для Ableton Live 12 (VST3 / AU)

Превращает простые звуки в текстуры в духе Fennesz: гранулярное облако, спектральный пэд-дрон,
«далёкий голос» (хор / скрипка, то появляется, то исчезает), перегруз, дилей, реверб, дрейф параметров.
Ставится на аудиотрек как эффект (источник — звук трека).

## Как получить плагин (сборка в облаке GitHub, ничего ставить не нужно)
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки (включая `.github`).
2. Вкладка **Actions** → дождитесь зелёной галочки `build` (5–15 минут).
3. Внутри запуска скачайте артефакт **Pool-Windows** или **Pool-macOS**.

## Установка
- **Windows:** `Pool.vst3` → `C:\Program Files\Common Files\VST3\`. В Live: Настройки → Plug-ins → включить VST3 и «Rescan».
- **macOS:** `Pool.vst3` → `~/Library/Audio/Plug-Ins/VST3/`, `Pool.component` → `~/Library/Audio/Plug-Ins/Components/`.
  Плагин не подписан, поэтому выполните в Терминале:
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Pool.vst3 ~/Library/Audio/Plug-Ins/Components/Pool.component`
- Лучше ставить на аудиотрек с источником (голос, гитара, клавиши, шумы) и играть звук 5–10 секунд,
  чтобы облако набрало материал.

## Управление
- Большое окно: тяните мышью — по горизонтали позиция в записи, по вертикали размер зерна.
  Оранжевые точки показывают, куда параметры «уплыли» из-за дрейфа.
- Заморозка фиксирует запись, пока вы играете с ручками. «Случайно» подмешивает случайные значения.
- 7 вкладок: основной звук, облако зёрен, пэд и дрон, далёкий голос, текстура, пространство, живость.
- Двойной клик по ручке — значение по умолчанию.

## Главный экран
- Четыре макро-ручки: **TEXTURE** (зернистость, перегруз, биткраш, шум), **MOTION** (разброс, обратное чтение, самоперезапись, скорость дрейфа), **SPACE** (реверб, хвост, шиммер, дилей, далёкий голос), **BLEND** (сухой звук ↔ облако). Центр — без изменений, двойной клик возвращает в центр.
- Кнопки режимов: **CAPTURE** (очистить запись и собрать новую), **OVERDUB** (выход возвращается в запись), **FREEZE** (заморозка), **EVOLVE** (автоматические переходы между сценами).
- Шестерёнка справа вверху открывает подробные параметры; пульс рядом — «случайно»; **A / B** — быстрое сравнение двух состояний.

## Чистый дрон
- **Нота пэда → «авто»** (крайнее правое значение): пэд сам подстраивается к ближайшей ноте исходного звука, корень удерживается и не прыгает вслед за материалом.
- **Стабильность** теперь ещё и усредняет спектр во времени: чем выше, тем спокойнее пэд.
- **Строгость** оставляет только гармоники выбранной ноты, **Фокус** оставляет только самые сильные тона записи.
- Пресеты «Чистый дрон» и «Дрон-хор» — отправная точка.

## Новое
- **Нота пэда / Строгость / Стабильность** (вкладка «Пэд и дрон») — пэд и далёкий голос держатся на выбранной ноте и звучат только гармониками.
- **Строй зёрен** — разброс высоты зёрен по полутонам, октавам и квинтам.
- **Самоперезапись** — выход возвращается в запись зёрен, лупа мутирует.
- **Хвост / Грязь хвоста / Шиммер** — длинный перегруженный реверб с октавой вверх.
- **Шум / Вокодер / Цвет / Следование** (вкладка «Текстура») — шумовое облако, повторяющее спектр звука.
- **Сцены A–D** — запишите четыре состояния (кнопки «Записать»), включите «Сцены ВКЛ» и двигайте «Позицию сцен» или включите «Эволюцию», чтобы плагин сам плавно переходил между сценами. Звук настраивайте при выключенных сценах, затем записывайте в слот; «В ручки» загружает слот обратно для правки.
- 31 пресет.

## Честные оговорки
- Проверено: сборка Linux, прогон аудио без NaN, точность сдвига высоты, запуск интерфейса и скриншот.
  **Не проверено:** Windows, macOS, работа внутри Ableton. Если CI упадёт, пришлите лог ошибки.
- Сдвиг высоты основного звука добавляет ~60 мс задержки на обработанном сигнале (компенсация не заявлена).
- Лицензия JUCE: бесплатная версия показывает заставку и имеет ограничения по выручке, для распространения
  проверьте условия на juce.com (либо AGPL).
- Автономный тест движка: `g++ -O2 -std=c++17 -pthread tests/engine_test.cpp -o t && ./t`
