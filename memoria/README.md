# Memoria — afterimage engine (VST3 / AU)

Эффект для Ableton Live: всё, что звучит на дорожке, попадает в общую память и кружит в ней.
Каждый круг материал немного темнеет и истончается, будто испаряется.
Пока играешь, память может приглушаться, а когда перестаёшь — наплывать.

## Как получить
GitHub собирает плагин сам: **Actions → memoria →** верхний запуск → **Artifacts → Memoria-macOS** (или Memoria-Windows).

## Установка на Mac
1. Распакуйте архив, положите `Memoria.vst3` в `/Library/Audio/Plug-Ins/VST3/`.
2. В Терминале, каждую команду отдельно:
```
sudo xattr -dr com.apple.quarantine /Library/Audio/Plug-Ins/VST3/Memoria.vst3
sudo codesign --force --deep -s - /Library/Audio/Plug-Ins/VST3/Memoria.vst3
```
3. Ableton → Настройки → Plug-ins → **Rescan** с зажатым Option.

## Управление
- **Режим:** GRAINS — гранулы над петлёй; DIFFUSE — кольцо из длинных allpass с плёночным дрейфом;
  NETWORK — 4 перекрёстно связанные линии (7–16 с); TAPES — две петли неравной длины (до 23 с).
- **Размер:** LONG / MID / SHORT — длина линий.
- **DECAY** — сколько памяти остаётся на каждом круге (вверху чуть больше 1, лимитер держит петлю).
- **WARMTH** — сатурация в петле и на выходе.
- **DYNAMICS** — влево: память приглушается, пока играешь, и наплывает после; вправо: тихие хвосты распускаются в дрон.
- **SPREAD** — разброс гранул / сколько звука перетекает между линиями.
- **DRIFT** — глубина медленных непериодичных LFO.
- **LAYERS** — каждый слой памяти получает свой характер: полосу частот (DARK / MID / BRIGHT / AIR), сдвиг высоты
  (например −12, +7, +12) и текстуру (TAPE / FOLD / CRUSH), а ещё своё место в стерео. В петле слои по-своему темнеют
  или светлеют. Карточки справа показывают характеры; клик по ним или кнопка **DICE** — перетасовать.
- **PING-PONG** — у каждого слоя своя пинг-понг задержка со своим временем, эхо прыгает L ↔ R.
- **TONE** (слева от кольца) — темнее ↔ ярче.
- **DEPTH** — глубокий упругий саб: октава вниз (−12), во второй половине ручки ещё одна (−24); саб пружинит с нотами,
  всё ниже 120 Гц сведено в моно.
- **SPACE** — большой зал: хвост до ~20 с, низ звучит дольше верха; зал слышит и вход, поэтому облако раскрывается сразу.
- **SHIMMER** (кнопка) — хвост зала поднимается на октаву (в 5TH — на квинту) и уходит вверх.
- **TAIL** (полоса под карточками) — частоты хвостов, 24 дБ/окт: левая точка срезает низ (15 Гц – 4 кГц), правая — верх
  (300 Гц – 20 кГц); двойной клик — сброс. Под капотом срезы чуть гуляют с DRIFT, а когда перестаёшь играть,
  хвост сам постепенно темнеет и истончается.
- Под капотом всегда: если середина (300 Гц – 3 кГц) выпирает, она мягко прижимается (до −6 дБ), а резкие атаки
  мокрого сигнала сглаживаются — звук не бьёт «в лоб». Сила растёт со SPACE.
  Светлые точки на полосе — переливы спектра (PRISM), их движение задаёт **DRIFT**.
- **CHAOS** — иногда вмешиваются случайные сбои: WARP (звук плывёт), STUTTER (заедание), REVERSE (кусок назад),
  TAPE STOP (остановка плёнки), DROPOUT (провал), SHUFFLE (слои перетасовываются). Чем выше, тем чаще; плюс лёгкая детонация.
- **RUIN** — шипение и треск записываются в память и стареют вместе с ней, куски памяти выветриваются (эрозия),
  выше середины петля теряет разрядность.
- **HARMONY** (над карточками слоёв): **OCT** — сдвиги слоёв только на октавы, всегда в тональности (по умолчанию);
  **5TH** — плюс квинта, одна нота лада может уйти; **FREE** — любые интервалы, включая кварты.
  Сдвиг высоты подстраивает фазу (WSOLA), поэтому октавы звучат чисто, без призвуков.
- **MIX**, **OUTPUT** (до +18 дБ; плавный лимитер на выходе держит пики без искажений).
- **LOW-CUT / HIGH-CUT** — сила деградации в петле (клик — следующая степень).
- **INPUT** — писать в память L+R, только L или только R.
- **FREEZE** — вход не пишется, память кружит без потерь. **REVERSE** — всё в обратную сторону.
  **BLUR** — размыть всё в облако; размытое понемногу дописывается в память, дрон со временем мягчеет.
  Перетасовать характеры слоёв — клик по карточкам. **ERASE** — стереть память.
- **VARY** — вариативность: раз в 8–16 с выбираются 2–3 параметра (SPREAD, DRIFT, LAYERS, PING-PONG, SPACE, TONE,
  WARMTH, DYNAMICS, DEPTH) и плавно, понемногу уходят в сторону; остальные возвращаются. Точка на ручке — текущее значение.
  Режим, размер, DECAY, MIX, OUTPUT не трогаются. Моно-выход остался параметром для автоматизации.
- 66 пресетов в 11 группах: **Течение** (первые четыре — тёплое мерцание в духе Fennesz, следующие четыре — плотный
  органный распад в духе Tim Hecker), **Дрон**, **Простор**, **Эхо**, **Текстура**, **Распад**, **Глубина**, **Хаос**,
  **Руины**, **Космос**, **Чисто**.
- Смена режима не стирает память: новый режим играет по старому материалу.

## Разработка
- Тональный отчёт по пресетам (полосы, наклон относительно входа): `g++ -O2 -std=c++17 memoria/tests/tone_report.cpp -o /tmp/tr && /tmp/tr`
- «Текучесть» пресетов на последовательности аккордов: `g++ -O2 -std=c++17 memoria/tests/flow_report.cpp -o /tmp/fr && /tmp/fr Течение`
- Детектор щелчков и зашкала по всем пресетам: `g++ -O2 -std=c++17 memoria/tests/click_report.cpp -o /tmp/cr && /tmp/cr`
- Тест движка без JUCE: `g++ -O2 -std=c++17 memoria/tests/engine_test.cpp -o /tmp/mt && /tmp/mt`
- Снимок окна (Linux): `cmake -S memoria -B build -DMEMORIA_TOOLS=ON && cmake --build build --target memoria_snapshot`,
  затем `xvfb-run build/memoria_snapshot_artefacts/Release/memoria_snapshot out.png 0 9`.
